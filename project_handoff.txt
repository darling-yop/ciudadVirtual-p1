### 5. LÓGICA DE NEGOCIO IMPLEMENTADA
═══════════════════════════════════════

- Sistema de turnos:
  - `Ciudad.procesarTurno()` ejecuta producción, consumo, ingresos, costos, felicidad, puntuación, actualización externa y registro.
  - `CityManager.iniciarCicloTurnos()` controla turnos automáticos con intervalo configurable.
  - Guardado automático cada 30 segundos en `CityManager.iniciarAutoGuardado()`.

- Sistema de recursos:
  - Producción: U1 produce electricidad, U2 produce agua, I2 produce alimentos.
  - Consumo: ciudadanos (electricidad, agua, comida); edificios consumen energía/agua salvo utilidades y parques.
  - Alimentos se restan y condicionan felicidad.
  - Si electricidad o agua quedan negativos, se finaliza el juego.

- Sistema de ciudadanos:
  - `Ciudad.#gestionarCrecimientoPoblacional()` crea nuevos ciudadanos si hay felicidad >60%, viviendas y empleos disponibles.
  - `Ciudad.#asignarAutomaticamente()` ubica vivienda y trabajo en edificios con capacidad libre.
  - `Ciudad.actualizarFelicidadCiudadanos()` aplica vivienda, empleo, clima y alimentos.

- Sistema de puntuación:
  - Base: `poblacion*10 + felicidad*5 + dinero/100 + edificios*50 + electricidad*2 + agua*2`.
  - Penalizaciones: desempleo, dinero negativo, electricidad negativa, agua negativa, felicidad baja.
  - Bonificaciones: desempleo 0, felicidad >80, recursos positivos, población >1000.

- Sistema de construcción:
  - `Ciudad.puedeConstruir()` valida costo, celda libre y adyacencia vial.
  - Vías `r` se pueden construir libremente en celda vacía.
  - Edificios requieren vía adyacente.

- Sistema de demolición:
  - `CityManager.demoler()` elimina contenido de mapa y remueve edificio.
  - Falla reembolso completo y sincronización total con UI.

- Sistema de rutas (Dijkstra):
  - Frontend `RouteRepository.calculateRoute()` envía grid binario + coordenadas start/end.
  - Backend Flask en `ms_smart_city-main/main.py`.
  - Fallback local BFS si backend no responde.

### 6. BACKEND
═══════════════════════════════════════
- Framework/lenguaje: Python + Flask
- Endpoint implementado: POST /api/calculate-route
  * Request exacto: {"map": [[0,1,...],...], "start": [fila,columna], "end": [fila,columna]}
  * Response éxito: {"route": [[fila,columna], ...]}
  * Response error: {"error": "mensaje"}
- Cómo correr: python main.py
- Puerto: 5000
